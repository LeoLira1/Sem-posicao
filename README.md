# Sem Posição

App Flutter (somente leitura) que lista os produtos do `estoque_mestre` que ainda
não aparecem em nenhum endereço do app Gôndolas (gôndolas, estantes, galpão,
barracão e `estoque_localizado`). Códigos do mesmo produto (cadastro `mapa_produtos*`
ou mesmo nome) são agrupados. O APK sai na aba Releases.
